# Case Studies

Case studies show how PySNE can be used to solve practical and theoretical nonlinear systems, explaining the problem formulation, methodology, and results.

## Available case studies

- **[Nonlinear Systems (SNE)](nonlinear-systems.md)**: Solving standard benchmarks of systems of nonlinear equations, demonstrating the solver's ability to find all roots for given problems.
- **[Multimodal Benchmarks](multimodal-benchmarks.md)**: Exploring PySNE's capability to locate multiple local and global optima of highly non-convex objective functions.
- **[Diophantine Equations](diophantine-equations.md)**: Applying the solver to find integer solutions for polynomial, exponential, and systems of linear and nonlinear Diophantine equations.
- **[Application Examples](application-examples.md)**: Demonstrating how PySNE handles real-world engineering and applied use cases, such as structural modeling.

## Suggested case study format

When contributing a new case study, we suggest following this format:

- Background
- Objective
- Mathematical system
- Search space
- Method
- Results
- Visualization
- Repository link
- Research references
