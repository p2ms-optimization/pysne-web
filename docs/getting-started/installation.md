# Installation

Install PySNE from PyPI when available:

```bash
pip install pysne
```

For development version:

```bash
git clone https://github.com/p2ms-optimization/pysne.git
cd pysne
pip install -e .
```

## Requirements

- Python 3.10 or newer
- NumPy
- SciPy
- Matplotlib or Plotly for visualization
